\section{Pedagogical tutorial}
\subsection{Problem}
Given a measured ordinario curve $Y_{\mathrm{ord}}$ and a paired bridge of
ordinario + special technique, produce model-derived synthetic values
\[
\widehat Y_t = Y_{\mathrm{ord}}\,e^{\widehat\delta}.
\]
\subsection{Recommended use}
Prefer model \textbf{M1} (exploratory default), Zenodo source \textbf{MEDIA}
(\texttt{Violin\_Media} column O = Media ff), sheet
\texttt{Predictions\_supported}, column \texttt{y\_pred}.
Cross-collection bridges require explicit transport mode
(\texttt{transport\_prior}). See \texttt{AUDIT\_RESPONSE.md}.

\subsection{Run history}
Each Preflight / Fit writes
\texttt{outputs/run\_history/<id>/RUN\_REPORT.html}
(all uploaded Excel names, config, operations, charts after Fit).
Twins: \texttt{RUN\_REPORT.md}, \texttt{run\_manifest.json}, CSV snapshots.
Index: \texttt{INDEX.md}. Code: \texttt{run\_history.py}, \texttt{run\_report\_html.py}.

\section{Core transport identity}
\[
\delta=\log\frac{Y_t}{Y_{\mathrm{ord}}},\qquad
\widehat Y = Y_{\mathrm{ord}}\,e^{\widehat\delta},\qquad
f=e^{\widehat\delta}.
\]
Code: \texttt{bridge.py} (build), \texttt{models/fit.py} \texttt{predict\_transfer}.

\section{Bridge}
Winsorize per technique at quantiles $q,1-q$. Acoustic prior applied
once at model coefficients, not per response.
Same-collection enforced by default; dual corpus IDs stored.

\section{Models}
\subsection{M0} Technique mean of $\delta$ (\texttt{\_fit\_m0}).
\subsection{M1 (exploratory default)} Cell means with pool $n_0=4$ (\texttt{\_fit\_m1}):
\[
\widehat\delta=\frac{n\,\widehat\delta^{\mathrm{cell}}+n_0\mu_t}{n+n_0}.
\]
\subsection{M2 (secondary)} Robust constant or WLS B-spline on MIDI
(\texttt{\_fit\_m2}). No spline extrapolation outside bridge MIDI.
\subsection{M3} Bambi/PyMC when installed; hard fail unless approx fallback authorized.
Optional \texttt{(1|corpus\_id)} only if a technique spans multiple corpora.

\section{Uncertainty}
\[
\big[\widehat Y e^{-1.96\sigma},\,\widehat Y e^{+1.96\sigma}\big].
\]
\section{Blocked CV}
Leave-one-pitch-block-out ($B=12$ semitones): MAE/RMSE on log $\delta$, MAPE on factors
(\texttt{validation/blocked\_cv.py} 30--120).

\section{Consistency audit}
Transport identity, strict dynamics map $f\leftrightarrow\mathrm{ff}$, MEDIA column O,
and M2 non-extrapolation verified. M3 corpus pooled means are audit-only;
Bambi point predictions intentionally use the M2 surface (v1.1 fix).
